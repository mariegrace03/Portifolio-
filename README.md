# Marie Grace Niyigena — Portfolio

Personal portfolio website showcasing my work as a Full Stack Developer: projects, experience, skills, and ways to get in touch.

**Live site:** [grace-portfolio-sepia.vercel.app](https://grace-portfolio-sepia.vercel.app)

## Pages

- **Home** — introduction, featured projects, and experience timeline
- **About** — background, education, and downloadable CV
- **Skills** — frontend, backend, mobile, and tooling skills
- **Projects** — web and mobile projects with live links
- **Experience** — internships and roles at Rwanda ICT Chamber, AZUL Tech, RG Consult, kLab Academy, and SheCanCode
- **Services**, **Blog**, **FAQ**, and **Contact**

## Tech Stack

- [Next.js 16](https://nextjs.org) (App Router) with React 19
- [Tailwind CSS v4](https://tailwindcss.com)
- TypeScript and JavaScript
- Font Awesome icons
- Deployed on [Vercel](https://vercel.com)
